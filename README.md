Логіка перевірки: У методі handleDelete(item, tr) прописана спеціальна умова. 
Система жорстко забороняє видаляти Викладача з ID = 1 (Дмитренко Поліна Кирилівна) та Дисципліну з ID = 1 (Основи програмування). 
Система вважає, що ці дані "пов'язані" з іншими таблицями.
